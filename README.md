# 🌀 BraynBrowser

Basit, hızlı ve minimal yapıda tasarlanmış bir masaüstü web tarayıcısıdır.  
C# ile geliştirilmiş olup **WebView2** motorunu kullanarak modern web siteleriyle uyumlu çalışır.

Bu proje; temel tarayıcı işlevlerini öğrenmek, WebView entegrasyonunu denemek ve masaüstü uygulama mimarisini pratik etmek amacıyla oluşturulmuştur.

---

## 🚀 Özellikler

- 🌐 **WebView2 tabanlı modern tarayıcı motoru**
- 🔍 **Google Search entegrasyonu**
- ⏮️ Geri – İleri navigasyon
- 🔃 Sayfa yenileme
- 🏠 Anasayfa yönlendirmesi
- ⭐ Minimal ve sade kullanıcı arayüzü
- ⚙️ Hafif ve hızlı çalışacak şekilde optimize edilmiştir
- 💻 Windows için tam uyumlu

---

## 🛠 Kullanılan Teknolojiler

- **C# (WinForms)**
- **Microsoft WebView2 Runtime**
- .NET Desktop geliştirme araçları
